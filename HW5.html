Exercise 1 — Riemann and Lebesgue integration

1.1 The two numerical approaches

Riemann-inspired. Partition the domain [a, b] into N subintervals of width h = (b−a)/N and add up (value of f at a point of the subinterval) × h. We use the midpoint rule and the left rule; Darboux sums (supremum or infimum on each piece) are used for the pathological cases.

RN = Σi=0N−1 f(xi*)·h

Lebesgue-inspired. Partition the range of f into K levels yk = m + k·h (h = (M−m)/K) and look at the preimages Ek = {x : yk ≤ f(x) < yk+1}. The simple function that equals yk on Ek lies below f, so its integral is a lower sum; using yk+1 gives an upper sum:

LK = Σk yk·μ(Ek) ≤ ∫f ≤ UK = Σk yk+1·μ(Ek) = LK + h·(b−a)
μ(Ek) = μ{f ≥ yk} − μ{f ≥ yk+1}

The measure of a preimage is not found by sampling: for every function below the set {f ≥ t} is described exactly (inverse functions, or bisection for sin x / x, which is decreasing on [0, π]). For the unbounded 1/√x the range is truncated at Y = 1 + √K with level width 1/√K, so only a lower sum exists. The Lebesgue method therefore needs a measure of level sets, the Riemann method only point values.

(d) Interpretation

  • Same limit. For continuous and piecewise-continuous bounded functions the two approximations converge to the same exact value (see table (a)): Riemann and Lebesgue integrals agree whenever the Riemann integral exists.
  • Accuracy and order. For smooth f the midpoint rule has error O(1/N²), while the Lebesgue lower sum only has error O(1/K) because the simple function is off by up to one level width h. The averaged sum (L+U)/2 improves on it for monotone pieces.
  • Discontinuities. For step functions both are exact or nearly so: the Lebesgue sum sees only two level sets of known measure, and the midpoint rule fails only by the cell containing the jump.
  • Unbounded f = 1/√x. The proper Riemann integral does not exist (f is unbounded); only an improper integral does. The midpoint rule converges slowly, like 1/√N. The Lebesgue integral exists as a genuine integral, and the layer-cake truncation also converges like 1/√K.
  • Efficiency. Riemann needs N function evaluations and no extra knowledge. Lebesgue needs K evaluations of the measure μ{f ≥ t}, which in practice means inverting f; cheap for monotone pieces, costly (bisection) for sin x / x, and unavailable for a general f. That is why Riemann sums dominate numerical practice and Lebesgue's strength is theoretical (limits, pathological functions).
1.5 Pathological functions: where the two approaches differ

Dirichlet function (1 on rationals, 0 on irrationals). Every subinterval contains both kinds of numbers, so upper Darboux sums are 1 and lower sums 0 for every N: not Riemann integrable. Riemann sums depend on the tags chosen (rational tags → 1, irrational tags → 0). The set of rationals is countable, so it has measure 0 and f = 0 almost everywhere: the Lebesgue integral is 0. A computer cannot test this directly (every floating-point number is rational), so the tags are handled symbolically.

Thomae function (1/q at p/q in lowest terms, 0 at irrationals). It is continuous at every irrational and discontinuous only on the rationals (measure 0), so it is Riemann integrable and both integrals equal 0. The upper Darboux sum is computed exactly: on each cell the supremum is 1/q for the smallest q such that a fraction p/q lies in the cell.

Dirichlet: Riemann sums have no limit (1 vs 0), Lebesgue sums are 0 for all K. Thomae: Riemann (upper Darboux and rational-tag sums) and Lebesgue agree; the upper sum falls roughly like (log N)/N, much more slowly than 1/N².

Exercise 2 — Numerical computation of the normal CDF

2.1 Definition
φ(t) = e−t²/2/√(2π)    Φ(x) = ∫−∞x φ(t) dt = ½ + ∫0x φ(t) dt    Φ(−x) = 1 − Φ(x)

The symmetry Φ(−x) = 1 − Φ(x) lets every method work on x ≥ 0 only (Hogg–McKean–Craig, §3.4: the usual z-tables list only z ≥ 0 for this reason).

2.2 Why Φ is not elementary: Liouville's theorem

The authors of the course notes remark that the integrand “does not have an antiderivative” in elementary terms; to be precise, it has one (the integral itself, or a power series), but none expressible with finitely many elementary functions (polynomials, exponentials, logarithms, algebraic functions and their compositions). This is a theorem of Liouville (1830s), put in its modern form by Rosenlicht (“Integration in Finite Terms”, Amer. Math. Monthly 79, 1972).

Liouville's theorem (exponential case). Let f, g be rational functions, g non-constant. Then ∫ f(x) eg(x) dx is elementary if and only if there is a rational function R with
R′(x) + g′(x)·R(x) = f(x), and then ∫ f eg dx = R(x)·eg(x).

Application. For the Gaussian, f = 1 and g = −x²/2, so we would need a rational R with R′ − x·R = 1.

  • If R is a polynomial of degree d ≥ 0, then R′ − xR has degree d + 1 ≥ 1, so it cannot equal the constant 1; R = 0 gives 0 ≠ 1.
  • If R has a pole of order m at some x₀, then R′ has a pole of order m + 1 while xR has a pole of order only m, so R′ − xR still has a pole and cannot equal 1.

Hence no such R exists and e−x²/2 has no elementary antiderivative; the same holds for e−x². Its integral is therefore defined as a new function.

Special functions: the error function

erf(z) = (2/√π) ∫0z e−t² dt    erfc(z) = 1 − erf(z)
Φ(x) = ½ [1 + erf(x/√2)] = ½ erfc(−x/√2)

This gives an exact analytical representation of Φ, but it only moves the problem: erf is not elementary either, so its values still have to be computed numerically (series, continued fractions, rational approximations, or numerical quadrature). Even calculators and libraries do exactly this.

2.3 Reference values found on the web

Reference values for Φ are obtained from the probability P = erf(z/√2) = Pr(|Z| < z), published with many digits: OEIS A178647 (z = 1), A110894 (z = 2), A270712 (z = 3), the table of the Wikipedia article “68–95–99.7 rule” (z = 0.5) and OEIS A379853 for the tail erfc(1/√2) (z = −1). Then Φ(z) = (1 + P)/2.

Sources: oeis.org/A178647, oeis.org/A110894, oeis.org/A270712, oeis.org/A379853; en.wikipedia.org/wiki/68–95–99.7_rule; faculty.etsu.edu notes on Hogg–McKean–Craig §3.4 for the theory. The digits were also cross-checked against an arbitrary-precision library; they agree to double precision.

2.4 Numerical methods implemented
  1. Trapezoid rule: Φ(x) = ½ + ∫0x φ, with n subintervals; error O(h²).
  2. Simpson's rule: same integral with weights 1, 4, 2, 4, …, 4, 1; error O(h⁴).
  3. Alternating power series of erf (Hogg–McKean–Craig): Φ(x) = ½ + (1/√(2π)) Σ (−1)k x2k+1 / (2k (2k+1) k!). Exact in theory but suffers cancellation for large x.
  4. Positive series: Φ(x) = ½ + φ(x) Σ x2k+1/(2k+1)!!, all terms positive, no cancellation.
  5. Abramowitz–Stegun 7.1.26 approximation of erf with a rational polynomial in t = 1/(1+0.3275911 z), maximum absolute error about 1.5·10⁻⁷ for erf.
  6. Hybrid (series + continued fraction): positive series for |x| < 3, and for |x| ≥ 3 the continued fraction of erfc, which gives the tail with full relative accuracy. Used as the “library-quality” method.

Conclusions

  • Trapezoid and Simpson need many evaluations of the exponential (about 16,000 for the trapezoid at 1e-10 and z = 3); Simpson is far cheaper but still much slower than a closed form.
  • The alternating series is cheap near 0 but loses digits for larger |x| because terms of size ex²/2 cancel; the positive series avoids this and converges fast up to moderate |x|.
  • The A&S formula costs one exponential but is limited to about 1e-7.
  • The hybrid method reaches machine precision at the cost of a few dozen operations, and keeps relative accuracy in the tails. This is the approach (series for the centre, continued fraction or rational approximations for the tails) used by numerical libraries.
  • Liouville's theorem explains why there is no closed form to fall back on; the erf representation is exact, but evaluating erf is itself a numerical task.
