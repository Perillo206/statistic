Ex. 1 — Deriving Knuth's and Welford's recurrences

1.1 Knuth's recurrence for the mean

Let Mn = (x₁ + … + xn)/n. Splitting off the last term:

n·Mn = (n−1)·Mn−1 + xn
Mn = Mn−1 + (xn − Mn−1)/n

Define the innovation δ = xn − Mn−1. Then Mn = Mn−1 + δ/n, and also xn − Mn = δ − δ/n = δ(n−1)/n (used below).

1.2 Welford's recurrence for the sum of squares

Let SSn = Σi≤n (xi − Mn)². Separate the last term and re-centre the others on Mn−1, using xi − Mn = (xi − Mn−1) − δ/n:

SSn = Σi<n [(xi − Mn−1) − δ/n]² + (xn − Mn)²
= SSn−1 − (2δ/n)·Σi<n(xi − Mn−1) + (n−1)·δ²/n² + (xn − Mn)²

Because the deviations from the mean sum to zero, Σi<n(xi − Mn−1) = 0, and xn − Mn = δ(n−1)/n:

SSn = SSn−1 + (n−1)δ²/n² + (n−1)²δ²/n²
= SSn−1 + δ²·(n−1)(1 + n − 1)/n²
= SSn−1 + (n−1)/n · δ²
= SSn−1 + δ·(xn − Mn)

1.3 Variance

sample variance (÷ n−1): s²n = SSn/(n−1), n ≥ 2
population variance (÷ n): σ̂²n = SSn/n
directly: s²n = ((n−2)/(n−1))·s²n−1 + δ²/n

Start with M₀ = 0 and SS₀ = 0. The new datum enters only through δ, so no second pass over the data is needed and no large sums of squares appear (numerically stable).

1.4 Code (core logic: 3 lines)

# Python
mean = ss = 0.0
for n, x in enumerate(data, 1):
    d = x - mean
    mean += d / n              # Knuth
    ss   += d * (x - mean)     # Welford
variance = ss / (n - 1)        # sample variance

1.5 How one update is computed, step by step

The whole state is three numbers: the count n, the running mean M and the running sum of squares SS. When a new value x arrives, the state is refreshed in six small steps (starting from n = 0, M = 0, SS = 0):

  1. Count: n ← n + 1
  2. Innovation: δ = x − Mold (how far the new value is from the old mean)
  3. New mean (Knuth): Mnew = Mold + δ / n
  4. Second deviation: ε = x − Mnew (distance from the new mean)
  5. New sum of squares (Welford): SSnew = SSold + δ · ε
  6. Variance: s² = SSnew / (n − 1), available from n = 2

Why it works: δ·ε = δ²(n−1)/n is exactly the increase of the sum of squares derived in 1.2, so each update costs a few operations and never re-reads the past data.
