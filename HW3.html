Model and simulation setup

Each of the m attackers is an independent run of the same campaign against n systems. Xi is the penetration score obtained on the i-th system; the Xi are i.i.d. Two models are compared:

Bernoulli: X ∈ {0,1}, P(X=1)=p → μ = p, σ² = p(1−p)
Rademacher: X ∈ {−1,+1}, P(±1)=½ → μ = 0, σ² = 1
Sn = ΣXi : E = nμ, Var = nσ²
Sn/n : E = μ, Var = σ²/n
Sn/√n : E = √n·μ, Var = σ²

2. Distributions across the m attackers for increasing n

Each row uses one common horizontal axis for all four values of n, so widening (Sn), shrinking (Sn/n), a stable bell (Sn/√n, Rademacher) or a drifting bell (Bernoulli) is visible directly. Red curve: normal approximation N(E, Var).

3. Law of Large Numbers: convergence in probability of Sn/n

Empirical P(|Sn/n − μ| > ε) over the m attackers falls to 0 and stays under the Chebyshev bound σ²/(nε²) and the Hoeffding bound. The pink curve shows the same event for Sn/√n (centred at its mean): it does not go to 0, because that normalisation keeps the fluctuations alive.

4. Variance under the different normalisations

Log-log slopes: +1 for Sn (variance explodes), −1 for Sn/n (variance vanishes, hence LLN), 0 for Sn/√n (variance constant, the only scaling that keeps a non-degenerate limit).

5. Central Limit Theorem: Sn/√n → N(0,1) in the Rademacher case

Left: Rademacher Sn/√n against the standard normal density for four values of n. Right: Kolmogorov–Smirnov distance to N(0,1) of the standardised score (Sn − nμ)/√(nσ²). It decreases roughly like 1/√n until it reaches the sampling-noise level (95% critical value ≈ 1.36/√m). The Bernoulli model also converges once centred and rescaled, but its raw Sn/√n drifts to +∞ because μ ≠ 0.

Effect of n (systems). A bigger target population makes the aggregate score larger in absolute terms but more predictable in relative terms: the attacker's penetration rate Sn/n concentrates around p, with relative uncertainty of order 1/√n. In the symmetric Rademacher case (every system either advances or sets back the attacker) there is no systematic progress: the net score is a random walk whose typical size is √n.

Effect of m (attackers). m does not change the distribution of a single attacker's score. It determines how well the simulation (or a defender's observation) resolves that distribution: histogram noise and the KS floor scale like 1/√m. If the attackers' scores are pooled, T = Σ Sn has mean m·n·μ and variance m·n·σ², so the average score per (attacker, system) pair has standard deviation σ/√(mn):

Assumptions: independent and identically distributed systems and attackers. Real systems are heterogeneous and attackers share tools, which correlates the Xi and makes the real spread larger than the i.i.d. values above.
